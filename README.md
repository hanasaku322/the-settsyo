# ザ・水道滞納者 v35

フリートーク重視版です。

## v35の変更点

- 滞納者の返答上限を 180文字 → 320文字 に拡大
- 雑談・冗談・意味不明な話にも、より自然に付き合うよう調整
- すぐに料金の話へ戻しすぎないように変更
- 会話が面白くなる場合は、2〜4文ほどフリートークしてよい設定に変更
- ただしゲーム性維持のため、最終的には水道料金・支払日・支払額・止水不安へ自然に戻す
- オウム返し禁止は維持
- ただし、短い引用やツッコミまで消さないように抑制処理を弱めた
- v33のエンディング多様化は維持
- 読み上げ機能は削除済み
- 音声入力のみ維持
- Render診断用 `/api/debug-gemini?code=8739` は維持

## トークン

返答が長くなるため、1回あたりの出力トークン消費は少し増えます。  
ただし、追加API呼び出しはありません。

トークンを使うのは、担当者の文章を送信してAI滞納者の返答を作る時だけです。

## Render設定

```text
Build Command: npm install
Start Command: npm start
```

環境変数:

```text
GEMINI_API_KEY=自分のAPIキー
GEMINI_MODEL=gemini-2.5-flash-lite
MAX_REQUESTS_PER_HOUR=80
NODE_OPTIONS=--dns-result-order=ipv6first
```
